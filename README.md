3. Написаны моки с помощью Mockito. Какие именно понадобятся — определено самостоятельно.
4. Написаны тесты на классы Feline, Cat и Lion.
5. Применена параметризация и реализован параметризованный тест.
6. Произведена оценка покрытие с помощью Jacoco: не менее 100% для классов Feline, Cat и Lion.
